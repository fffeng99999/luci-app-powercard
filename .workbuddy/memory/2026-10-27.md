# 2026-10-27 工作日志

## luci-app-powercard 新增两大功能（v1.0.0 → v1.2.0）

### 1. 定时开关机（v1.1.0）
- UCI `schedule` 段存规则（enabled/time/action/weekdays），`sync_cron` 同步到 `/etc/crontabs/root`
- cron 行带 `# powercard-schedule` 标记，重建时只清自己的行，保留用户其他 crontab 条目
- 前端卡片支持多规则（≤32）、七天点选（7位掩码，位0=周日）、启停开关、中文摘要行
- cron 直接调用 `/usr/libexec/rpcd/powercard run_scheduled <on|off|force>`

### 2. 关机保护/看门狗（v1.2.0）
- 需求：软关机后电脑有时系统关了但风扇仍转；软关机（手动或定时）后开始计时，到点仍检测到开机则自动 force 强制断电；时长可配，默认 10 分钟
- 实现：`power off` 成功（BODY 非空）→ `watchdog_arm` 写 `/tmp/powercard-watchdog`（epoch，tmpfs 重启自动清）；`on`/`force` → 解除
- cron 每分钟 `watchdog_tick`：无标记即退；到点查 `/api/status`，`pc_on` 为 true/1 → POST force；false/0 → 清除；空响应或解析不出 pc_on → 保留标记下分钟重试
- 配置存 `powercard.main.watchdog_enabled/watchdog_minutes`（1~180 分钟校验）
- `get_watchdog` 返回 armed/remaining，前端布防期间显示倒计时（10s 轮询）
- Makefile 加 postinst 钩子 `ensure_cron`，安装/升级后自动写入每分钟 tick 行
- `sync_cron` 在看门狗启用时自动追加 `* * * * * ... watchdog_tick` 行

### 关键坑（已验证）
- jsonfilter 无数组长度/多表达式 → 逐索引逐字段探测
- busybox ash 无 `${s:i:1}` → 取首字符用 `${rest%"${rest#?}"}`
- 前导零八进制 → 用 `${hh#0}` 而非 `$((10#$hh))`
- 测试 mock 注意：curl POST 分支必须输出响应体，否则 BODY 恒空、布防逻辑测不到
- 脚本用 `[ -x /usr/bin/curl ]` 硬编码路径探测，mock 环境需 sed 成 `command -v curl`
